# Decentralized Systems

- [Bitcoin](bitcoin.md) — Services and tools for Bitcoin software developers.
- [Ripple](ripple.md) — Open source distributed settlement network.
- [Non-Financial Blockchain](non-financial-blockchain.md) — Applications of Blockchain beyond finance.
- [Mastodon](mastodon.md) — Open source decentralized microblogging network.
- [Ethereum](ethereum.md) — Distributed computing platform for smart contract development.
- [Blockchain AI](blockchain-ai.md) — AI and machine-learning projects built on Blockchain.
- [EOSIO](eosio.md) — A decentralized operating system supporting industrial-scale apps.
- [Corda](corda.md) — Open source Blockchain platform designed for business.
- [Waves](waves.md) — Open source Blockchain platform and development toolset for Web 3.0 apps and decentralized solutions.
- [Substrate](substrate.md) — Framework for writing scalable, upgradeable blockchains in Rust.
- [Golem](golem.md) — Open source peer-to-peer marketplace for computing resources.
- [Stacks](stacks.md) — A smart contract platform secured by Bitcoin.
- [Algorand](algorand.md) — An open-source, proof of stake Blockchain and smart contract computing platform.
- [ZeroNet](zeronet.md) — A decentralized web-like network of peer-to-peer users.
- [Cosmos SDK](cosmos-sdk.md) — Modular framework for building app-specific blockchains in Go.
- [Tor](tor.md) — A free overlay network for enabling anonymous communication.
- [ATProto](atproto.md) — Open, decentralized network for building social apps.
