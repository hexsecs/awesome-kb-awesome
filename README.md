# Awesome Lists (Awesome KB)

An OpenShelf 1.7 knowledge base imported from
[sindresorhus/awesome](https://github.com/sindresorhus/awesome).
Part of the [Awesome KB](https://github.com/hexsecs/awesome-kb) network.

**[Browse the knowledge base](index.md)** — every curated external-resource
bullet has a generated entity stub. Linked child bullets are included;
the contents menu, sponsors, and unlinked parent labels are excluded.
The Related section is included as discovery resources.
Linked lists are not recursively imported.

Source headings supply categories. Descriptions are retained verbatim;
entries without a description receive a neutral generated summary.
Resource status remains unknown; last_checked is omitted until verified.

## Reproduce and validate

Run python3 tools/ingest.py --date 2026-11-04, then python3 tools/check.py
and openshelf lint .

The default input is the immutable raw/2026-11-04 capture. Use --source
with an upstream checkout for a later ingest. UUIDs and creation dates
remain stable and authored brief/full/deep pages survive source updates.
